General
Upon registering on our Partners Reseller Program, you will receive a unique Secret Key.
It's crucial to securely store this Secret Key, as it serves as a key component in accessing our API.

Secure Storage:
Security Reminder: Ensure to keep your Secret Key confidential and stored securely. It's recommended to store
it in a safe location to prevent unauthorized access.
IMPORTANT: You will not be able to use MyProxyApi - Proxy Reseller API while a Partner manager didn't gave your
Secret Key.

1. Secret ID Usage: The Secret Key is exclusively used in the getToken endpoint. This endpoint is specifically
designed for generating a Bearer Token.
2. Bearer Token Usage: Once you've obtained the Bearer Token using your Secret ID, you will use this token for
authentication in subsequent API calls.

Authorization in API Calls:
Bearer Token: For all other API endpoints, including those related to managing products, orders, and user
accounts, you will need to include the Bearer Token in the Authorization header of your HTTP requests.
By following these steps, you'll be able to authenticate and access our API seamlessly, empowering you to leverage
the full capabilities of our Partner Proxy Reseller Program.
